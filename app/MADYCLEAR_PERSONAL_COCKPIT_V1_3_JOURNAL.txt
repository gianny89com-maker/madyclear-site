MADYCLEAR PERSONAL — COCKPIT V1.3 — AUTONOMOUS CORE
Date : 13/09/2026
Base : MADYCLEAR Personal Cockpit V1.1 (conservée, modification ciblée)

OBJECTIF
Faire du nouveau cockpit le poste de commandement du MADYCLEAR Autonomous Core tout en conservant le mode local-first, le CRM, les devis, les projets, les sauvegardes JSON et la PWA existante.

MODIFICATIONS LIVRÉES
1. ACCUEIL / COCKPIT
- Nouveau panneau « Autonomous Core — Système nerveux MADYCLEAR ».
- État système : LOCAL / EN LIGNE / DÉGRADÉ / CRITIQUE.
- Compteurs : actions AUTO, validations, alertes critiques, événements en file.
- Dernière synchronisation et activité récente.
- Bouton de synchronisation manuelle.

2. DIGISTAFF
- 4 modes : Question, Action, Proposition, Diagnostic.
- Question : recherche/synthèse locale.
- Action : commandes sûres locales (scan priorités, relances, synchronisation, sauvegarde).
- Proposition : création d’une action soumise à validation.
- Diagnostic : état du Core, files et alertes.

3. CRM CLIENTS
- Nouveaux champs : source du contact, canal autorisé, mode d’automatisation.
- Mise à jour du journal Core à chaque création/modification.
- Conservation des anciennes données localStorage avec migration progressive.

4. AUTONOMOUS CORE LOCAL-FIRST
- Journal d’activité local.
- File d’événements locale.
- Traitement AUTO local des actions sûres.
- File VALIDATION pour les actions engageantes proposées par DIGISTAFF.
- Alertes CRITIQUE bloquantes.
- Scan autonome horaire tant que la PWA est active.
- Aucun secret stocké dans le navigateur.
- Sans cloud, le cockpit reste utilisable à 100 % sur l’appareil.

5. PASSERELLE N8N / CORE
- Champ de configuration du webhook distant dans Réglages.
- Synchronisation optionnelle des événements vers n8n/Core.
- En cas d’échec réseau, passage en état DÉGRADÉ sans perte des données locales.
- Reprise de synchronisation possible dès le retour de la connexion.

6. CANAUX PRÉPARÉS
- Cockpit local : actif.
- WhatsApp direct : actif (liens existants).
- n8n/Core : prêt à brancher par webhook.
- Gmail : préparé / à connecter côté orchestrateur.
- Google Calendar : préparé / à connecter côté orchestrateur.
- Google Drive : préparé / à connecter côté orchestrateur.

7. VERSION / PWA
- Version interface : 1.3.0.
- Service worker : cache madyclear-personal-1.3.0.
- Manifest : MADYCLEAR Personal Cockpit V1.3.
- Anti-cache des fichiers principaux conservé.
