MADYCLEAR Personal — Cockpit V1.5 — KeepConnected Bridge
Date : 13/09/2026

OBJECTIF
Adapter les principes AppKeepConnected au cockpit MADYCLEAR sans promettre une persistance H24 impossible pour une simple PWA.

INTEGRE MAINTENANT
- Détection réseau ONLINE/OFFLINE.
- Heartbeat au démarrage, au retour dans l’app, au focus et toutes les 15 min lorsque l’app est active.
- File locale de reprise pour actions compatibles.
- Relance automatique de la file au retour du réseau.
- Journal des événements de connexion.
- Déclencheurs configurables V1 : réseau et horaire.
- Interface KeepConnected dans le cockpit.
- Compatibilité Action Engine V1.4 conservée.
- Local-first conservé.

ARCHITECTURE CIBLE
Cockpit PWA ↔ KeepConnected Bridge ↔ Autonomous Core ↔ n8n/services.
Pour une vraie exécution H24 téléphone verrouillé/app fermée :
Cockpit PWA ↔ Android Companion Service (Kotlin) ↔ Autonomous Core.

ANDROID COMPANION — À CONSTRUIRE PLUS TARD
- Foreground Service.
- BOOT_COMPLETED.
- WorkManager/JobScheduler.
- BroadcastReceiver réseau/batterie/Bluetooth selon permissions modernes Android.
- WakeLock uniquement pendant tâches critiques.
- Room/SQLite local.
- Notification persistante de service.
- API locale sécurisée / deep links vers le cockpit.

LIMITES / AJUSTEMENTS
- Une PWA ne peut pas garantir une exécution H24 après fermeture.
- iOS limite fortement les tâches persistantes.
- Les changements Wi-Fi/Bluetooth nécessitent APIs/permissions natives spécifiques.
- Un serveur HTTP local exposé sur le téléphone n’est pas recommandé comme mécanisme principal ; préférer webhooks cloud sortants + push/FCM pour réveil.
- REQUEST_IGNORE_BATTERY_OPTIMIZATIONS doit être utilisé avec prudence et seulement si justifié.
