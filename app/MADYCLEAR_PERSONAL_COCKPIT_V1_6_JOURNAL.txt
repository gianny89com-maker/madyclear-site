MADYCLEAR Personal — Cockpit V1.6 — Portal Hub
Date : 13/09/2026

OBJECTIF
Adapter les meilleures idées du concept portail No-Code 2026 au cockpit MADYCLEAR sans perdre l'architecture local-first.

AJOUTS
- Portail rapide sur l'accueil.
- Deux contextes : Entreprise / Vie perso.
- Raccourcis visuels pilotés par Action Engine.
- Capture vocale via Web Speech API lorsqu'elle est disponible.
- Fallback vers saisie texte si la dictée navigateur n'est pas disponible.
- Bouton Avant / Après ouvrant la caméra / sélecteur photo du téléphone.
- Captures locales historisées.
- Raccourci Heures salarié.
- Raccourci Vide-poche.
- Raccourci Nouveau prospect.
- Raccourci Préparer ma journée.
- Google Drive / Sheets considérés comme canaux optionnels, pas comme base maître.

AJUSTEMENTS IMPORTANTS
- Google Sheets n'est PAS la base centrale du cockpit : trop fragile pour les données métier privées et l'autonomie hors ligne.
- Base maître actuelle = stockage local + futur Supabase/PostgreSQL pour synchro sécurisée.
- Google Drive reste excellent pour documents/photos, mais en connecteur optionnel.
- La voix est intégrée au portail, sans dépendre d'un Custom GPT séparé.
- Pas d'automatisation qui exige de manipuler le téléphone en conduisant : utilisation mains libres / à l'arrêt uniquement.
- Les widgets natifs Android/iOS restent pour le futur Companion natif.

ARCHITECTURE V1.6
Portail Hub -> Action Engine -> KeepConnected -> Autonomous Core -> n8n/connecteurs.
