Portée utilisée : https://www.googleapis.com/auth/webmasters. Elle permet de lire les performances Search Console et de soumettre le sitemap.

Ne colle jamais le secret OAuth dans le chat. Saisis-le uniquement ci-dessous : il sera envoyé directement au backend MADYCLEAR et stocké dans Supabase Vault.

Ce qui sera synchronisé

  • clics, impressions, CTR et position par jour sur environ 90 jours ;
  • les principales requêtes Google sur 28 jours ;
  • les principales pages vues dans Google sur 28 jours ;
  • le sitemap officiel https://www.madyclear.fr/sitemap.xml.

La demande manuelle « Demander une indexation » reste une action de l’interface Search Console ; elle n’est pas exposée par l’API Search Console standard.
